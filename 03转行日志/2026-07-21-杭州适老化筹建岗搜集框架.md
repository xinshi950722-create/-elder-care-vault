## 一、搜什么（关键词）
- 适老化设计 / 适老化改造 / 养老空间设计
- 养老机构筹建 / 项目筹建 / 开业筹备
- 养老院长储备 / 运营筹备
- 地域限定：杭州 + 浙江

## 二、去哪搜（渠道）
- 招聘平台：Boss 直聘、前程无忧、猎聘
- 杭州本地：民政局官网 / 公众号、养老机构官网、行业协会
- 备注：岗位实情以招聘平台和机构官网为准，动手前二次核实

## 三、记什么（对应 JD 对比表字段）
每搜到一条 JD，按这 8 列填一行：
1. 岗位名
2. 机构类型（居家 / 社区 / 机构 / 政府）
3. 核心职责
4. 任职要求（学历 / 证书 / 经验）
5. 你的建筑师优势契合度（高 / 中 / 低）
6. 到管理岗距离（近 / 中 / 远）
7. 薪资区间
8. 来源链接

## 四、怎么判断（优先级）
- 稀缺优先：能用"一级建筑师 + 适老化设计"做差异化切口的岗排前
- 复合岗优先：筹建 + 运营筹备 交叉岗优于纯运营助理
- 到管理距离近的优先

## 五、辩证提醒
- 招聘 JD 是机构理想画像，实际入职可谈。别被"要求 X 年养老经验"劝退，你的设计底子是硬通货
- 搜的时候顺手记机构名，后续直接投或熟人内推比海投有效
- 框架是手段，目标是验证"筹建 vs 运营"判断并锁定 2-3 个目标岗
