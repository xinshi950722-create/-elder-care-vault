# 2026-07-28 周二实战演练（篮球轻日）

> 今日定位：不增量、不深挖。只练一个能力——被家属拍桌子时，怎么既守住合规、又救回信任。
> 形式：AI 扮投诉家属，你扮社区养老服务中心主任。一轮一反思，吃力点补进模块清单难点栏。

## 评分尺（直接取自 [[养老院运营模块清单]]，不另起炉灶）

**模块五 家属关系** 看三件事：投诉件数趋势 / 沟通触点 / 续约率。最狠指标 = **投诉处理后的转介延续率**（家属还愿不愿意介绍人进来）。
- 你的回应是在"修复信任"还是"自我保护"？修复 = 透明、担责、给后续动作；保护 = 辩解、推诿、冷处理。

**模块六 合规** 看三件事：照护记录完备率 / 事故险情上报率 / 零约束零虐待。最狠指标 = **险情自主上报率**（敢不敢自己先说）。
- 你敢不敢主动、完整地把事故和记录情况讲清楚（"自己说的比被查到的多"）？记录有没有写、能不能应对检查？

## 你的回应框架（开口前先想这四点）

1. **共情确认**：先接情绪，不急着辩事实
2. **事实透明**：事故报没报、记录写没写，按合规"应报尽报"
3. **当下行动**：送医 / 家属陪同 / 立即上报
4. **后续闭环**：复盘、整改、回访，这一步决定投诉后的转介延续率

## Round 1 场景（AI 开第一句，你接）

背景：你管辖的社区养老服务中心，一位 82 岁、轻度失能的阿姨今天上午在活动区摔倒，髋部骨折，已送医。家属下午来接人才从护工口头得知，中心没主动通知。

家属（AI 扮，拍桌子）：
> "我妈今天上午在你们这儿摔了，股骨头骨折！你们现在才让我知道？我下午来接人，护工还轻描淡写说'小事一桩'。你们到底报没报？记录写了没有？我怀疑你们想瞒过去！要是落个残疾谁负责？"

**你的任务**：以中心主任身份，用上面四点框架回应。写下来（或直接回我）。

## 自测四问（回完自己先打分）

- 我有没有先接住情绪，而不是先辩解？
- 我有没有主动把"报了没、记了没"讲清楚（自主上报，不是等查）？
- 我有没有给出立刻能落地的动作（陪同、上报、预案）？
- 我有没有约定下一步触点（回访/说明会），给信任留修复通道？
