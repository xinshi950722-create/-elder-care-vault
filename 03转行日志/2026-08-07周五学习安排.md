# 2026-08-07 周五 · 模拟面试全真跑

> 任务（来自 [[2026-08-03本周AI学习计划]] 周五四节）：AI 扮面试官全真跑，三分钟陈述 + 挑刺接住。
> 关联：[[2026-08-07周五模拟面试]] · [[AI运营工作流地图]] · [[2026-07-31周五定位表达演练]]

## 操作步骤（约 1.5h）

1. 读 [[2026-08-07周五模拟面试]] 的场景与三分钟陈述框架，先背熟「我是谁 / 我能交付什么 / 一个真实作品」
2. 写一版陈述稿（文字即可），连同对 Q1~Q4 的接住发我
3. 我扮面试官按真实节奏挑刺，你接住，来回两三轮打磨到能脱口
4. 收尾：把定稿写回面试笔记第四节

## 产出

- [[2026-08-07周五模拟面试]] —— 场景 + 陈述框架 + 四道追问挑刺 + 你的应答位

## 辩证检查

- 陈述讲「路径」不讲「愿望」：锚定运营总监 / 院长层级，用三件套证明可达
- 挑刺先认再翻，不硬扛；每个翻盘点都挂真实作品或数字
- 全真跑的价值在「被挑战时还能把逻辑说顺」，比背稿重要
