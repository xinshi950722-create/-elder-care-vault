# WorkBuddy 四段式提问法

> 学 AI 的第一硬技能。会提问，AI 才给得出你要的东西。
> 关联：[[养老管理岗位入门大纲]]

## 一、四段式结构

好的提问 = 角色 + 任务 + 约束 + 格式。四段齐全，一次就能拿到能用的答案。

| 段 | 作用 | 例子 |
| --- | --- | --- |
| 角色 | 让 AI 进入某个专家视角 | 你是一名做了 10 年的养老机构院长 |
| 任务 | 说清你要它做什么 | 帮我梳理一家 100 床养老院开业前要办的证照 |
| 约束 | 划边界，防跑偏 | 只讲杭州，按办理先后排序，标注归口部门 |
| 格式 | 指定输出长什么样 | 用表格，三列：证照名 / 归口部门 / 办理顺序 |

## 二、可抄模板

```
你是一名【角色】。
请帮我【任务】。
要求：【约束1】；【约束2】；【约束3】。
用【格式】输出。
```

## 三、养老场景示范三条

**示范 1 行业认知**
```
你是一名研究中国养老行业的分析师。
请帮我讲清养老的三种业态（居家 / 社区 / 机构）分别怎么赚钱。
要求：只讲盈利模式；每种业态给 1 个真实存在的运营方举例；语言通俗，不用行话。
用表格输出，三列：业态 / 盈利模式 / 举例。
```

**示范 2 学习规划**
```
你是一名帮零基础转行者做学习规划的教练。
请帮我设计一份 4 周入门养老运营的自学计划。
要求：我每天只有 1 小时；每周一个主题；每周末给一个可交付的小产出。
用清单输出，按周分组。
```

**示范 3 信息加工**
```
你是一名擅长做会议纪要的助理。
请把下面这段养老政策原文压缩成 5 条要点。
要求：每条不超过 20 字；保留关键数字；末尾标一句这对求职者的影响。
用编号列表输出。
（粘贴原文）
```

## 四、多轮追问收窄

第一轮拿到初稿后，别重开新问题，用追问把它逼准。

- 加约束：上面第 3 条太笼统，展开成 3 个可执行动作
- 换视角：如果站在家属角度，还会补哪一条
- 要反面：这个方案最大的风险是什么，怎么规避
- 逼具体：给我一个杭州本地的真实例子

## 五、今日练习（周三模块一）

1. 用模板自己写 1 条养老提问，四段齐全
2. 丢给 WorkBuddy，看输出
3. 至少追问 2 轮，把答案逼到能用
4. 把最终答案存成一篇 Obsidian 笔记，链回本篇

## 辩证提醒

提示词技巧是入口，不是终点。真正拉开差距的是你脑子里有没有好问题。AI 只能放大你的思考，放大不了空白。所以每天练提问的同时，多往养老行业里扔真实困惑，工具才有东西可撬。
