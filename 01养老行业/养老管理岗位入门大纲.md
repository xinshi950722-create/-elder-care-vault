# 养老管理岗位入门大纲（MOC）

> 这是地图笔记。每一条子主题都可以点成独立笔记，用 WorkBuddy 查、Obsidian 沉淀、GitHub 备份。

## 一、行业认知（先看清楚赛道）

- 中国老龄化数据与政策背景（银发经济写入国家战略）
- 养老服务体系三层：居家 / 社区 / 机构
- 典型业态：公办机构、民办非营利、营利性养老院、CCRC 持续照料社区、社区嵌入式站点、认知症专区
- 入场玩家：地产、物业、医疗、保险、科技多方下场，机会在交叉处

## 二、岗位地图（你要去的地方）

- [[养老机构运营管理]]：院长 / 副院长 / 运营经理（你的目标岗）
- 筹建岗：新院选址、设计、证照、开业筹备
- 照护管理：护理部主任、照护主管
- 评估与质量：[[老年人能力评估师]]、质控专员
- 社区与居家：站点运营、上门服务调度
- 职能支持：餐饮、康复、活动、人力、财务

## 三、能力模型（岗位到底要什么）

- 硬技能：运营管理、适老化标准、风险评估、证照合规、预算与排班
- 软技能：跨部门协调、家属沟通、危机处理、团队带教
- 你的差异化切口：建筑师的空间思维 + 系统思维 + 一级注册证，在 [[筹建与适老化设计]] 上比从护理干起更快触达管理岗

## 四、证书路线（考证即学习路径）

对接你的长期规划，按此顺序推进：

- [[养老服务师初级]]：零基础可报，国家职业资格，最先拿（入场券）
- [[养老护理员中级]]（四级）：进入行业后做实操背书
- 满约 4 年（建筑学按其他专业计）：报 [[养老服务师中级]]
- 并行：社工初级 / 中级、老年人能力评估师（三级）、养老机构负责人培训合格证
- 后段：健康管理师三级（门槛已高，第三方评价发证）
- 提醒：报考条件以浙江 / 杭州当年官方公告为准，务必二次核实

## 五、知识模块（逐块啃）

- 政策法规：《老年人权益保障法》、国标《养老机构服务安全基本规范》
- [[适老化设计]]：你的建筑师底子直接迁移，做差异化
- 运营管理：入住率、客单价、人效、投诉处理
- 老年医学常识：失能等级、认知症、营养、康复
- 风险与合规：跌倒、噎食、消防、意外处置流程

## 六、30-60-90 天行动

- 30 天：行业认知 + 报名养老服务师初级 + 搭好 Obsidian 知识库骨架
- 60 天：实地跟岗或访谈 1-2 家机构 + 读完 2 本运营书 + 启动护理员中级备考
- 90 天：产出一份「某机构运营诊断」小报告（作品集），提交 GitHub 留存

## 七、资源与下一步

- 政策原文、国家标准文本、行业研究报告
- 本地渠道：杭州民政局、养老服务行业协会
- 工具分工：WorkBuddy 翻译与提炼，Obsidian 沉淀成网，GitHub 备份与展示

## 辩证视角（先想明白再发力）

- 考证容易滑进"收集证书"的陷阱。企业最终看你能不能管住一家院。证书是门票，运营实战才是上岗证。
- 建筑师背景不要丢。筹建与适老化是你进场的差异化切口，比从护理一线干起更快摸到管理岗。
- 英语一般不必慌。养老管理本土性极强，英文资料只是补充，WorkBuddy 当翻译桥足够用。
- 政策与标准年年有更新。大纲里的法规条目以最新官方发布为准，动手前再核一遍。
